# platinum-mobius
I appear a multifaceted and difficult to comprehend individual. This project aims to remedy that somewhat, by pasting all of my faces to one surface. Hence, a mobius strip. (This is where I collect links of everything I have done, since I'm not necessarily proud enough to show it all off everywhere.)

Maybe you could consider this a portfolio of sorts? Maybe it will turn out more like a journal. I don't want to be famous, so I think I will intentionally engineer this to be unpopular.
